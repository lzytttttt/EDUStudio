## 1. 登录页改版：账号密码式正式页面

**改动**：`shell/LoginScreen.tsx` 由「选身份卡即登录」重构为正式的账号密码登录页，登录身份（教师/学校管理/教育局）收进表单内的身份选择器。

**布局**（评审修订后）：登录卡居中（max-w 400px），卡内自上而下：品牌头（Logo + EDUStudio + 教育 Agent 工作台）→ 账号 → 密码（明文切换）→ 登录身份三选一 → 登录按钮（提交态 loading）→ Mock 模式提示。无营销文案，信息紧凑。

**背景动效**（呼应「卡片简报 + 工作台」产品特色）：

- 点阵网格打底 + 三枚 `animate-drift` 漂移光斑（primary/mint/coral 柔色）；
- 4 张 `animate-float` 漂浮「简报卡片」骨架（四角环绕、近大远小）+ 2 个「迷你工作台窗口」骨架（三栏：任务列表/对话流/文档面板，红黄绿窗控点）；
- **鼠标视差跟随**：`--mx/--my`（-1..1）驱动，光斑 ±34px、卡片 ±16px、工作台 ±9px 分层位移，登录卡 perspective 微倾斜；
- **点击迸裂**：光环扩散（burst-ring）+ 四色粒子飞散（burst-bit，`--bx/--by` 变量入关键帧）；
- `prefers-reduced-motion` 下漂浮/漂移/视差/迸裂全部自动关闭。

**兼容性**：身份选择按钮沿用 `role-card-*` testid，新增 `login-account` / `login-password` / `login-submit`；三条 E2E（critical-path / demo-wizard / visual）已同步为「填表 → 选身份 → 提交」流程。**登录页视觉基线已随两轮改版重新生成。**

## 2. 界面字号：拖拽式连续调节，全局生效

**入口**：设置弹层 → 界面字号（拖拽滑杆）。

### 2.1 全局缩放机制（评审修订后）

- `settingsStore.fontSize`：**px 数值**（12–22 连续可调），`FONT_SIZE_MIN/MAX/DEFAULT = 12/22/14`；
- **应用链路**（`main.tsx` → `applyAppearance`）：
  1. 根字号缩放：`html.style.fontSize = 16 × 档位/14 px` —— 所有 rem 类工具类（`text-xs/sm/base`、间距、圆角等）整体等比缩放，覆盖侧边栏、顶栏、底部导航、抽屉、徽标、时间戳等**全部 UI 文字**；
  2. 阅读区精确值：内联 `--content-fs = 档位 px`（对话气泡 / Markdown 文档 / 编辑器 / 输入框）；
  3. ≥18px 记 `<html data-font="xlarge">`：`.minor-info` 次要信息隐藏与 Agent 轨迹放大（高龄用户适配保留）；
- **硬编码清理**：源码 156 处 `text-[Npx]` → `text-[Nrem]`（÷16 精确换算，默认档零视觉差异）；
- **移动端联动**：底部标签栏高度 `--tabbar-h: 3.25rem` 随字号缩放，中栏让位 `calc(var(--tabbar-h) + env(safe-area-inset-bottom))` 恒等对齐，大字号下输入框仍不被遮挡。

### 2.2 拖拽滑杆

- `FontSizeSlider`（`SettingsDialog.tsx` 内）：Pointer Events 零依赖，复刻 `Resizer` 交互范式——点击/拖拽轨道调值、方向键微调（Home/End 到边界）、双击重置 14px、拖拽中禁选文本、`role="slider"` 无障碍完整；
- 滑杆旁实时显示 `14px · 标准`，下方提供实时预览句；档位称呼仅作展示：≤13 小 / 14–15 标准 / 16–17 大 / ≥18 超大；
- **旧数据迁移**：`normalizeFontSize()` 兼容历史持久化的字符串档位（small→13 / medium→14 / large→16 / xlarge→20），非法值回退 14。

### 2.3 界面字体设置（已按评审移除）

首版曾提供默认/宋体/楷体/黑体四选一（`--font-ui` 变量方案），评审认为非必需，已完整回退：store 字段、设置面板区块、CSS 变量、tailwind `fontFamily.sans` 桥接均移除，字体恢复系统默认栈。

## 3. 移动端优化

| 项 | 问题 | 实现 |
| --- | --- | --- |
| 工作台底部菜单遮挡输入框 | 中栏固定让位 52px，但 iOS 安全区使实际标签栏更高，输入框被压住 | 底部标签栏自身加 `pb-[env(safe-area-inset-bottom)]`；中栏让位改为 `pb-[calc(var(--tabbar-h)+env(safe-area-inset-bottom))]`（`--tabbar-h: 3.25rem` 随全局字号缩放），两者高度严格对齐 |
| 简报 banner 文字过多 | 小屏顶部一行塞满日期/来源/按钮长文案 | 日期 `hidden sm:inline`；「导入成绩」移动端缩为图标（保留 aria-label）；「跳过简报，直接进入工作台」移动端显示短文案「工作台」；数据新鲜度按钮维持 sm+ 显示；边距收紧（px-4 / mx-4） |

既有移动端能力保持：iOS 输入防缩放（≥16px）、简报决策栏安全区避让、触控去延迟、简报滑卡完整触控。
