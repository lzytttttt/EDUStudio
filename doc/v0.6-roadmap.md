# v0.6 路线图 · 自进化技能系统（Self-Evolving Skills）

> 基于 v0.5.1 交付现状制定。v0.5 已完成：SourceProvider 数据源 / CSV 成绩导入 / 分享短链与批注回流 /
> 任务链跨端同步 / 通知中心 / 课标与跨文档 Agent 工具 / 上下文压缩与 token 预算 / 视觉回归与 Lighthouse /
> Docker 部署 / Key 生命周期与导出水印。Vitest 82 例 + E2E 7 条全绿。
> v0.6 主线：**Harness 层自进化技能系统 + 可直观演示剧本 + 三栏拖拽调宽**。

## 背景与目标

v0.5 后产品已具备「多轮 Agent 执行 × 真实数据 × 协同闭环」的完整骨架，但 Agent 能力存在三类差距：

1. **经验不留存**：每次任务从零推理，同类任务重复消耗；踩过的坑、验证过的最优路径没有沉淀通道；
2. **Mock 演示缺故事线**：剧本按关键词零散命中，缺少一条「能力成长」的连续演示线，向决策者展示时说服力弱；
3. **桌面布局固定**：三栏宽度写死（左 288/320、右 400/440），不同屏幕与阅读习惯无法调整。

v0.6 引入 Hermes 式 **Self-Evolving Skills**：任务完成后自动复盘提炼经验为可复用技能，跨会话持久化；
后续同类任务直接命中调用；技能在使用中持续进化（版本递增、触发词扩充、使用统计）。
生命周期闭环：**技能发现 → 自动沉淀 → 复用命中 → 进化**。

## 验收标准（可演示）

- [ ] 工作台发送一条内置剧本未覆盖的任务，执行完成后轨迹出现「已沉淀新技能」，技能库面板出现 v1 学习技能；
- [ ] 再次发送同类任务，轨迹出现「命中技能」徽标，按沉淀步骤直接执行，使用次数 +1；
- [ ] 发送变化任务（新增要求），技能版本 +1，进化时间线新增「refined」记录；
- [ ] 点击「自进化演示」一键播放三幕：发现 → 复用 → 进化，全程旁白讲解，可重置重复演示；
- [ ] API 模式下命中技能注入 system prompt（trace 可见 skill_hit），LLM 提炼留接口骨架；
- [ ] 桌面端拖拽左右分隔条调整三栏宽度，刷新后保持；双击重置；移动端抽屉不受影响；
- [ ] CI 全绿：Vitest 新增用例 + tsc 零错误 + E2E + 包体门禁。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 触发词提取噪声导致误命中 | 分段 + 停用词/动词前缀剥离 + 长度窗口（2–12 字）+ 上限 4 个；匹配要求完整包含 |
| 技能库膨胀 | 学习技能上限 50 条；触发词去重合并；「清空学习技能」一键重置 |
| 演示不可重复 | 演示向导启动前自动清空学习技能；提炼为确定性纯函数，同输入同结果 |
| 内置技能与剧本行为漂移 | 内置技能由 AGENT_SCRIPTS 派生（单一事实源），未命中技能库时行为与 v0.5 一致 |
| 拖拽与移动端冲突 | Resizer 仅 md+/xl+ 渲染；抽屉逻辑不变；宽度 clamp 防止中栏过窄 |

**存量问题修复**：复核包体门禁时发现「全部 JS ≤ 230KB」自 v0.4 设定后从未随 vendor 拆分与 recharts 引入重校——用 HEAD worktree 实测 v0.5.2 基线总包体已达 238.6KB（v0.5 交付仅复核了主 chunk，总包体为潜伏失败）。v0.6 按基线 + 本次新增（约 7KB）+ 余量将总预算校准至 250KB，并在 `scripts/budget.mjs` 注释中记录依据。

实现要点（与计划的偏差说明）：

1. **三层执行链收敛为两层检索**：`matchSkill` 已包含内置剧本技能（由 AGENT_SCRIPTS 派生、学习优先排序），内置剧本命中与学习技能命中统一走技能检索，trace 以 `origin` 区分——行为与计划等价，代码更简；
2. **学习技能执行补 done 收尾**：提炼时排除一次性话术（reflect/text/done），学习技能步骤不含 done，编排器在执行后补发收尾文本；
3. **寒暄停用词**：触发词提取增加寒暄/时间停用词表，避免「你好」类输入沉淀垃圾技能；
4. **演示剧本触发词已验证**：幕1 沉淀 v1（研学活动方案/行程/安全预案/预算表），幕2 含触发词直接命中，幕3 不含 v1 触发词原文但提炼出「预算」与「预算表」重叠 → 合并进化 v2，三幕闭环确定性可重复。
