## 0. 五条结论

1. 〔事实〕2026-09 的三周内，Meta Muse（9-08）、Manus Cue（9-28）、OpenAI dots（9-29）密集发布，个人 Agent 正从「问答」转向「常驻 + 主动 + 代办」[S3][S4][S6][S8]。
2. 〔事实〕「Dot」是两个产品：New Computer 的 Dot 已于 2025-10 停运并关停公司 [S1][S2]；OpenAI 在运营的产品名是 dots（复数）[S3]。引用必须区分。
3. 〔推断〕它们验证了「事找人」的直觉，但没有验证留存与 ROI：主动介入、记忆、身份与权限都还是半成品。
4. 〔推断〕教育是天然补位：有学校时钟、长链路事务、强合规审批，恰是通用助理缺的三件基础设施。
5. 〔建议〕差异化：不做更聪明的输入框，做「已经把事干到只差签字」的虚拟教研组。

## 1. 三个产品是什么

### 1.1 Dot：先拆同名

| | New Computer Dot（2024–2025） | OpenAI dots（2026– ） |
| --- | --- | --- |
| 是什么 | 前苹果设计师 Jason Yuan、前 Kensho 工程主管 Sam Whitmore 创办；定位「会随你成长的 AI 朋友 / 内心的活的镜子」，主打长期记忆与个性化对话 [S2] | 「常驻型智能体」：每个 dot 有独立云端电脑与浏览器、4000+ 应用插件，由 GPT-6 Astra 驱动，经 ChatGPT 桌面 / 网页 / 移动端、Slack、Teams 交互 [S3][S5] |
| 主动/异步 | 陪伴型对话，非任务托管 | 后台「proactive research」：不用时主动找活，但工具被限制为只读（不能发消息 / 改内容 / 控浏览器）；可关掉界面继续跑 [S3] |
| 记忆 | 强（人格 + 长期记忆） | 学偏好、思维方式与「好」的标准 [S3] |
| 授权 | 无审批概念 | 内置规则 + Custom Rules（允许 / 需批准 / 禁止）+ auto-review + Activity View；改密码等敏感动作永远人做 [S3] |
| 商业模式 | 免费；据报获 OpenAI 基金投资（未证实）[S2] | 首个 dot 含在 Pro（$100/月起）与 Business Premium；Enterprise（含 Edu）管理员开启后可 beta；未来加购 dot，并推 specialist dots 与「teams of dots」[S3][S4][S5] |
| 现状 | **官方已宣布 winding down 并关停公司，Dot 于 2025-10-05 停运**；原因是两位创始人方向分歧、各自发展，非被收购 [S1] | 在运营；2026-11-03 起增加 GPT-6.1 Terra 模型 [S3] |

〔事实〕Dot 官方称「数十万用户」（hundreds of thousands），但第三方数据显示 iOS 上线至停运累计下载仅约 2 万余次、无安卓版 [S1][S2]。〔推断〕记忆 / 陪伴型产品的失败主因是留存与单位成本，不是「记忆不够好」。

### 1.2 Muse = Meta 的消费级个人 Agent（2026-09-08）

〔事实〕Meta 称其为「首个面向所有人的个人 AI Agent」：消息式交互（Muse App / WhatsApp），说出目标即生成计划并自行推进；关闭 App 后继续工作，有变化或需要审批时才回来；发邮件、付款前确认；记忆可「忘记」；提供完整审计轨迹；运行在 Muse Secure VM，独立 Sentinel Agent 守门，未获批不出网；免费为主、订阅解锁更多 [S6]。首发美国 iOS / Android / muse.ai，10-27 进入新加坡 [S6]。〔事实〕上线 12 天 iOS 下载 180 万（ChatGPT 同期 130 万），美国移动 DAU 64.2 万；不到两周被安全研究员发现 0-day 可劫持窃取凭证；电话功能被曝由外包员工冒充 AI；亚马逊以「未授权 AI 代理」封禁其代购 [S4][S7]。

### 1.3 Cue = Manus 的「有身份」个人助理（2026-09-28）

〔事实〕Manus（蝴蝶效应，创始人肖弘）随 2.0 发布 Cue：每个 Agent 配独立邮箱、电话号码、数字钱包与专属电脑，可自主沟通、接电话、在预算内付款；多个 Agent 可进同一群聊接力（调研场地 → 整理名单 → 起草文稿）[S4][S8]。海外邀请制免费，iOS 待审，国内版筹备中 [S4][S9]。〔事实〕钛媒体一周实测：邮件最顺；电话与支付因地区 / 账号跑不通；多 Agent 群聊「谁在回应谁、谁收尾」不清、私聊与群聊信息不对齐；同题（Q4 传播方案）产出不显著优于豆包 / WorkBuddy；预埋的冲突未被主动发现；主动推断「推理成本持续发生、推送未必合时宜」[S9]。

### 1.4 横向对照

| | 交互模型 | 主动 / 异步 | 记忆 | 授权 / 审批 | 商业与现状 |
| --- | --- | --- | --- | --- | --- |
| Dot(NC) | 陪伴对话 | 否 | 强（人格 + 长期） | 无 | 已停运 |
| dots(OpenAI) | 消息 / 语音，多端 + Slack/Teams | 强（后台只读研究） | 学偏好与标准 | 规则 + 审批 + 活动视图 | 订阅制，在运营 |
| Muse(Meta) | 消息式，WhatsApp 内 | 强（关 App 续跑，需批才回） | 强，可 forget | 审批 + 审计 + Sentinel | 免费 + 订阅，扩张中 |
| Cue(Manus) | 独立 App + Agent 群聊 | 强（退登续跑） | 任务级 | 预算内自主，身份独立 | 邀请免费，早期 |

〔事实〕三者均为面向消费者的**通用**个人助理，均非教育产品；dots 仅在 Enterprise（含 Edu）工作区支持 beta 接入 [S3]。

### 1.5 同名与「未证实」

〔事实〕检索「Dot AI」会被美国运输部 DOT、词典释义淹没；Muse 另有 muse.ai（指向 Meta）、muse.io 建站平台、muse.mu 乐队、Muse Code 编码 agent；Cue 也有同名工具。本文所指见 1.1–1.3，检索噪声见 [S20]。〔未证实〕New Computer 获 OpenAI 基金投资（媒体称）；Cue 正式定价与国内上线时间；Muse 的真实 DAU / 付费转化（无第三方独立数据）[S7]。

## 2. 验证了什么、踩了哪些坑

〔事实〕**验证**：① 需求真实——Muse 首 12 天 180 万下载、DAU 64.2 万；② 范式成立——Muse 的胜负手被归结为「记忆 + 主动循环」与「权限安全架构」；③ 商业形态在演化——dots 按「首个 + 加购」卖，还预告 specialist dots 与团队 dots [S3][S4]。

〔事实〕**坑**：

1. **下载 ≠ 留存 ≠ 付费**：Muse 无第三方独立 DAU / 付费数据；ChatGPT 在 10 亿周活下付费率仅 5%，Muse 免费档每周送 1 亿 token，转化只会更低 [S7]。
2. **单位成本高**：每人一台云端 VM，单用户成本可能约 $50 / 月；Meta 2026 资本开支指引 1300–1450 亿美元，Q2 自由现金流仅 7.84 亿；Muse 需算力大降或用户月购 >$1000 才可能盈利 [S4][S7]。
3. **主动变噪音**：Cue 实测主动推断推理成本持续、推送未必合时宜，甚至会形成打扰 [S9]。
4. **权限 / 身份 / 责任未解**：0-day、外包冒充 AI、平台封禁；调查显示仅 8% 美国人愿把密码交 Meta，83.6% 受访青年担心隐私、53.4% 最担心高权限 Agent；Cue「给 Agent 独立身份」与千问 Go!「借用户身份」是两条都未跑通的路 [S4][S9]。
5. **通用助理缺场景锚点、缺交付闭环**：Muse 场景是购物 / 旅行，dots 是通用办公；Cue 接不进微信 / QQ / 班级群；多 Agent 编排成本高而产出无显著优势 [S3][S5][S9]。
6. **记忆是昂贵资产**：Dot 以长期记忆与人格为核心，仍于 2025-10 停运 [S1][S2]。

〔推断〕可迁移教训：记忆不是壁垒，**记忆 → 场景 → 交付物 → 授权责任** 四段链路缺一不可；先证明「省下的时间 > 使用与授权成本」，再谈自主。

## 3. 「事找人 + 异步托管」十条设计法则

| # | 法则 | 外部锚点 | 对 EDUStudio 的含义 |
| --- | --- | --- | --- |
| 1 | **准备度法则**：只推「已完成的活」 | dots 强调「把你的事按你的方式做完，甚至在你开口前」[S3]；Muse 有变化 / 需批才回来 [S6] | 决策卡必须附成品 + 差异摘要，教师只做「采纳 / 改一句 / 退回」；准备度 <80% 只进后台，不打扰 |
| 2 | **异步 = 离开是常态** | Muse 关 App 续跑、Cue 退登续跑 [S6][S9] | 教师一句话 → 计划确认 → 去上课；回来只处理「需要我」的节点 |
| 3 | **默认只读，行动分级授权** | dots 后台研究只读、敏感动作永远人做 [S3] | 授权分级（只读 / 草稿 / 审批执行 / 白名单自动）；对外动作永不可全自动 |
| 4 | **审批门是一等状态** | dots Custom Rules + auto-review [S3]；Muse 发信 / 付款前确认 [S6] | 审批门可暂停该分支、其余并行；批准 / 改 / 驳回三态与原因 chip 入库 |
| 5 | **打扰预算 × 时间窗** | Cue 主动推送的副作用 [S9] | 每日主动推送 ≤5 次、每次 ≤2 条；21:00–07:00 静默；低价值只进战情台 |
| 6 | **决策收件箱 + 摘要** | inbox / digest 原语；Muse 审计轨迹 [S6] | 战情台是决策队列而非消息流；下班前一份 digest 收口 |
| 7 | **交接契约：typed artifact** | Cue 群聊混乱 = 无交接协议 [S9]；dots specialist dots 有独立身份与权限 [S3] | Agent 间只传 typed 产物 + citations，不传全对话；共享事实快照 + 溯源 |
| 8 | **多 Agent 需证明 1+1>2** | Cue 多 Agent 产出不优于单体，用户不会为「协作本身」买单 [S9] | 每个演示必须有「单体做不到」的时刻（数字交叉校验 / 语气差异 / 合规），否则退化为单 Agent |
| 9 | **记忆：命名空间 + 可撤销 + 低成本** | Dot 停运 [S1][S2]；Muse 可 forget、按 App 授权 [S6] | 每 Agent 独立记忆命名空间；教师可见可删；只存结构化偏好，不存全量对话 |
| 10 | **可问责**：身份 / 溯源 / 撤回 | 身份归谁、权限谁授、出错谁担是 Cue 实测的底层难题 [S9]；Muse 审计轨迹 [S6] | 每个产物标「谁做的 / 用了哪些数据 / 改了哪版」；对外以教师名义但需教师签名 |

〔建议〕第 11 条**成本护栏**：Mission 级 token / 时间 / 调用预算，80% 出预算决策卡、100% 强制收尾 [S7][S9]；纯前端虽无真实账单，UI 也要把成本建模出来，否则演示答不了「校长为什么买单」。

## 4. K12 教师证据 → 设计约束

〔事实〕

- 光明日报 × 中国教育科学研究院 12 省调研：92.1% 教师每天在校（含课后服务）>9 小时，32.5% >11 小时；78.6% 每周 >45 小时，30.3% >55 小时（劳动法上限 44）；班主任周工作 56.27 小时 vs 非班主任 50.36 小时；「最想减轻」前五：迎接检查、写教学外材料、评比比赛、课后服务、家长工作 [S10]。
- 国家社科基金课题对 1154 名教师的调查：周均工作 54.5 小时，课堂教学仅占 22% [S11]；李镇西对 2787 名教师的调查：真正用于教学及准备不足 1/4，3/4 是非教学任务（材料、表格、迎检、创建活动）[S12]。
- 2025-11 教育部仍发文压减非教学负担：禁巡河护林 / 上街执勤 / 打卡留痕，法定节假日与寒暑假原则上不安排专任教师值班 [S13]。
- 政策端：《教育强国建设规划纲要（2024—2035）》要求「促进人工智能助力教育变革」「深化人工智能助推教师队伍建设」[S14]。

〔建议〕五条设计约束：

| # | 约束 | 依据 |
| --- | --- | --- |
| C1 | 单次交互 ≤3 分钟、随时可中断恢复；长任务必须后台化并保存上下文快照 | 92.1% 在校 >9h、课间被切碎 [S10] |
| C2 | 交付物优先于对话：表格、材料、通知、家长信等「文书型非教学任务」价值最高 | 3/4 时间在非教学事务 [S12]；最想减轻清单 [S10] |
| C3 | 家校沟通是高情绪、高风险场景：审批门 + 语气合规 + 留痕 / 撤回三件套必备 | 家长工作进「最想减轻」前五 [S10]；Muse / dots 均设审批门 [S3][S6] |
| C4 | 数据敏感（未成年人）：最小授权、本地可删除；对齐 dots「Edu 工作区默认不训练」的承诺 | [S3]；83.6% 隐私担忧 [S4] |
| C5 | 学校时钟（课表 / 校历 / 考试 / 教务 DDL）是最强触发器，也是「为什么是我们」的护城河 | 长链路样本见 roadmap §1.1 |

## 5. 国内竞品地图与空白

〔事实〕主流形态：

| 形态 | 代表 | 已解决 | 结构性缺口 |
| --- | --- | --- | --- |
| 备课 / 课件 | 希沃教学大模型（AI 协同备课 / 课堂反馈 / 微格教师；2024-09 已建 14 个示范区、覆盖 1000+ 校、生成 7.5 万+ 份课堂反馈报告）[S15]、101 教育 PPT、WPS AI | 单点生成与课堂分析 | 不进任务流，不跨场景 |
| 组卷 / 作业 | 学科网 · 组卷网 [S17]、讯飞星火教师助手（大单元规划 / 教学设计 / 课件，广东 500+ 校）[S16]、智能批阅机、数智作业 | 题库、组卷、批改 | 交题目与分数，不交决策包 |
| 班级 / 家校 | 希沃班级优化大师（评价 + 报表 + 家校同步，永久免费）[S18]、钉钉 / 企业微信班级群 | 记录与通知 | 缺代写代发、缺合规审批 |
| 智慧平台 | 国家中小学智慧教育平台 + 省市平台 [S19] | 资源分发与治理 | 不做教师个人事务编排 |
| 通用 AI | 豆包（2026-06 MAU 3.82 亿）、千问 Go!、腾讯 Marvis、元宝 [S4][S9] | 通用生成与入口 | 缺教师角色、班级事实与授权锚点 |

〔推断〕空白三处：① 跨场景长链路编排（备课 → 组卷 → 作业 → 家长会 → 复盘）；② 有角色分工与审批的「虚拟教研组 / 班务幕僚团」；③ 教师个人偏好与班级事实的可复用记忆（带溯源）。

〔建议〕一句话差异化：**别人给教师一件更快的工具；EDUStudio 给教师一个会接班、懂分寸、可问责的虚拟教研组。**

## 6. 对 v1.0 的三个直接结论

1. **为什么现在做**：2026-09 三个头部产品同时把个人 Agent 推向大众，范式窗口刚打开 [S3][S4][S6][S8]。
2. **为什么战队**：外部已验证「记忆 + 主动循环 + 权限架构」三件套，但通用助理缺场景锚点；dots 自己也在走「专员 dot + 团队 dot」路线，说明分工 + 编排是方向，而 Cue 群聊的混乱说明**交接契约才是成败点** [S3][S9]。
3. **为什么是教育**：教师的时间碎片与长链路文书事务是公开事实 [S10][S11][S12]，政策又明确要求减负与 AI 助教 [S13][S14]——需求、政策、范式三浪叠加。

〔待 Lead 决策〕

- ① 02 / 03 / 04 的 L0–L3 语义不一致（02 递增到全自动、03 以「批准后托管」为中档、04 把 L3 定为对外二次确认），建议在 02 定唯一契约并回改 03 / 04。
- ② roadmap 与演示脚本里的「Dot」建议统一写作 OpenAI dots，并加注 New Computer Dot 已于 2025-10 停运，避免评审误读。
- ③ 演示是否加一段「通用助理做不到的三件事」对比（场景锚点 / 交付物闭环 / 可问责授权）。
