# v1.0 交互方案 · 事找人 + 异步托管（含 10 分钟演示脚本）

> 交互规格，不含代码；契约见 02，编制见 04。对齐现状：README 三屏流程、`src/apps/briefing`（六类卡 / 滑卡落章）、`src/apps/loom`（画布 / 拓扑 / checkpoint）、`doc/v0.9.5-roadmap.md`（`md-cite` 溯源、真 docx/xlsx、任务链接入）。

## 0. 五条结论

1. 首页从「简报卡流」改为「今日战情（待我决策）」：先决策、后发现，简报退为发现区。
2. 四个目的地：战情台 / 作战室 / 交付物 / 战队——三栏工作台改为作战室，文档面板升为交付物，Loom 退居作战图。
3. 事找人 ≠ 通知：每天最多 3 次主动推送、每次 ≤2 条；其余只进战情台，不打扰。
4. 托管四档 L0–L3；家长发送 / 成绩对外 / 处分与安全 / 对外承诺四类硬门永远人批、不可上调。
5. 10 分钟演示一条主线：课间两个决策 → 一句话委托 → 离场回来 → 多 agent 挑错 → 授权调整收尾。

## 1. 信息架构与导航

### 1.1 登录后的新首页：今日战情

```
┌ 今日战情 · 11月10日 周一 · 09:42（课间） ┐
│ 待你决策 3 · 战队在办 2 · 今日已托管 4 · 约省 2h  │
│ [ 一句话交给战队去做…              ] ＋新委托     │
├ 待我决策（本窗口已推 2 条） ─────────────────────┤
│ ① 3 封家长信 18:00 前要发    P=0.91  [1 分钟]    │
│ ② 分层作业比例待定（函数单调性 61%）P=0.76 [50 秒] │
│ ③ 教研听课记录回执    下一课间提醒                 │
├ 战队在办（3 条） ────────────────────────────────┤
├ 今日简报 · 发现区（默认折叠）6 张 · 已批 4 ───────┤
└───────────────────────────────────────────────────┘
```

结构：①战情条（3 个数字）②待我决策 ③在办摘要 ④简报发现区（原卡流折起）。源：新 `decisionStore`/`missionStore` + `briefingStore`/`focusStore`/`taskFlowStore`。交互：竖滑、主按钮决策、顶部一句话委托；无「全部已读」。状态：空 / 加载 / 错过 / 堆积 / 只读。

### 1.2 四个表面（区块 → 数据源 → 交互 → 状态）

- **战情台 Inbox（首页）**：战情条 / 待我决策 / 在办摘要 / 发现区 / 委托。源：decision、mission、briefing、taskFlow、focus。交互：决策、委托、溯源、稍后。状态：空 / 错过 / 堆积 / 只读。
- **作战室 Mission**：左=使命/战队状态；中=作战动态流（谁·做了什么·产物·用时）+ 插话；右=作战图（Loom 投影：TeamTask DAG / checkpoint）+ 交付物；头=进度 N/M·暂停/撤回。源：missionStore、chatStore、loomStore、artifactStore。交互：插话、暂停、撤回、审批。状态：计划中 / 执行中 / 等审批 / 已交付 / 失败。
- **交付物 Artifacts**：作战包列表（按 mission）+ 包详情（主文档/附件/执行摘要/溯源/待办/导出）+ 版本历史。源：artifactStore、eval、sources、mission。交互：预览、编辑、导出、分享、反馈。状态：生成中 / 未读 / 待验收 / 已归档。
- **战队 Team**：6 成员卡 + 授权矩阵 + 周报。源：新 `teamStore` + memoryStore + skillStore + trace。交互：看战绩、调授权、删偏好、看周报。状态：待命 / 执行中 / 等你审批 / 暂停 / 学习中。

## 2. 事找人机制

### 2.1 触发源（对齐主 roadmap：只五类可触发打扰）

| 源 | 现状锚点 | 典型事项 |
| --- | --- | --- |
| Agent 产出/等审批 | `artifactStore` 未读、checkpoint、`eval` 低分 | 家长信待批、教案验收 |
| 数据异常（需判断） | `seed.ts` 函数单调性 61%、专注度 86 | 分层作业、习题课 |
| 教务/任务链截止 | `taskFlowStore`、`tf-3`、`tf-4` 督导 3/5 | 回执、督导整改、填表 |
| 课表/校历节点 | 明天习题课、D-3 家长会、公开课周五上报 | 提前 1–3 天准备 |
| 周期性复盘 | 周五战报、简报发现卡、家长咨询 | 不推送，只进战报/发现区 |

### 2.2 优先级公式

`P = 0.40·U + 0.30·I + 0.20·R + 0.10·M`（与主 roadmap 同口径，0–1 分）

- U 紧迫度：距截止/上课/发送窗口的剩余时间归一化（今天或 2h 内=1）。
- I 影响面：涉及学生数、是否硬截止、是否对外（对外或全班=1）。
- R 准备度 0–100%：<80% 不得主动打扰，只进后台/战报。
- M 教师适配：与历史决策/偏好的匹配度（复用简报决策与记忆）。
- C 决策成本 1/2/3 分钟档：超过当前窗口允许成本则顺延；同分 C 小者先。

阈值：P≥0.65 主动推送；0.45–0.65 只进战情台；<0.45 留战报/后台。
算例：家长信 0.91、分层作业 0.76 推；督导回执 0.61 进战情台；简报提问卡 0.38 战报。

### 2.3 打扰预算

- 每天最多 **3 次主动推送**（早读前 1 / 课间 1 / 午休 1），每次 ≤2 条；下班前与 21:30 战报只进战情台，不占预算。
- 同一事项每天 ≤1 次；连续 2 个课间不重复推；同一卡连续 2 次未读 → 静默至次日。
- 推送 ≠ 可见：战情台始终可看；静默期紧急项只站内红点、不推送。质量指标是决策转化率与跳过率。

### 2.4 时间窗

| 窗口 | 时间 | 单次预算 | 允许决策成本 | 只放 |
| --- | --- | --- | --- | --- |
| 早读前 | 07:00–07:30 | 1 次 / ≤2 条 | ≤1 分钟 | 今天必须发生 |
| 课间 10 分钟 | 1 次/课间，连续 2 个课间不重复 | ≤2 条 | ≤1 分钟 | 已就绪的审批门 |
| 午休 | 12:30–13:00 | 1 次 / ≤2 条 | ≤5 分钟 | 家长信、学情小结 |
| 下班前 | 17:00–17:30 | 不占预算 | ≤10 分钟 | 验收、返工、明日准备 |
| 晚间战报 | 21:30 | 只读，不要求动作 | — | 今日摘要 |
| 静默 | 22:00–06:30 与上课时段 | 0 | — | 只入战情台 |

### 2.5 DecisionItem 信息结构

```
┌ ① 3 封家长信 · 今天 18:00 前发出      建议 L1 ┐
│ 为什么现在找你：课间窗口 + 截止 2h + 3 位家长   │
│ 已做到：家校沟通官 2 稿 + 合规校验 ✓  ███░ 90% │
│ 需你 1 分钟 · ▸看原文 ▸看收件人(3) ▸溯源       │
│ [批准发送] [改一改] [驳回并说明]   ↑收藏 ←稍后   │
└─────────────────────────────────────────────────┘
```

必填字段：一句话结论（动词 + 对象 + 后果）｜为什么现在找你（触发源、时间窗、截止、证据 chip）｜已做到什么程度（进度、产物缩略、哪个 agent、是否降级数据）｜需你几分钟｜三个动作（主=批准、次=改一改、兜底=驳回/稍后）｜托管等级建议 Lx + 一句理由｜状态（新 / 已看 / 稍后 / 已委派 / 完成 / 过期）。

### 2.6 空态 / 错过 / 堆积

- **空态**：不空白——「今天没有需要你决定的事」+ 3 条在办动态 + 委托入口 + 周报。
- **错过**：标「错过本课间 · 顺延下一课间」；截止 <2h 升 U 优先展示（不额外推送）；过期转「补救卡」（延期话术 / 补救方案，仍需人批）。
- **堆积（>6 条）**：分「今天必须 / 今天可以 / 不必今天」三组，只出 1 条建议「先做这 3 件 · 合计 8 分钟」并支持批量；低风险 L1 转「仅存档」；连续 2 天堆积提示调授权。

## 3. 委托与托管

### 3.1 七步主链路

一句话委托 → 计划确认 → 异步执行 → 动态可见 → 插话 / 暂停 / 撤回 → 审批门 → 作战包与返工。

### 3.2 计划确认单（PlanConfirmSheet）

字段：目标重述｜拆解（3–6 个 TeamTask，标 assignee、依赖、并行组）｜交付物（typed：文档/表格/消息稿/清单）｜审批门（插在哪、依据哪条规则）｜预计（agent 用时 + 教师介入 2 次 ×1 分钟）｜成本（token 预算，沿用 `tokenBudget` 60000）｜本次不做。
动作：按此开战 / 改计划（改目标、增删任务、调授权）/ 先做第一步 / 取消。低风险同类可勾「以后同类不再确认」→ 写偏好。

### 3.3 异步可见与「离开再回来」（主场景）

- 动态流：按时间倒序（`08:12 学情分析师 · 核验月考数据 ✓ · 12s`），可展开 trace（复用 `AgentTraceView`），顶部战队状态条。
- 回来三步卡：「你离开了 1 分 30 秒 · 战队完成 4 个环节 · 1 件在等你」→ 时间线只显示 3 条关键节点 → 一键跳首个审批门。
- 诚实边界：纯前端不假装云端后台——页签隐藏/关闭即暂停在安全点，回来显示「继续」；刷新按 localStorage 恢复（running→queued 续跑）；不伪造离开期间的推送。
- 未读语义：只有「未读动态」，没有「未读通知」；自己参与过的那条永远置顶。

### 3.4 插话 / 暂停 / 撤回 / 审批门

- 插话＝增量约束，不重启：总指挥须回执「收到，影响 2 个任务，重排后 +3 分钟」。
- 暂停：全部 / 单个任务，停在安全点；撤回：删除未执行任务，已产出保留为草稿。
- 审批门在战情台与作战室双处出现（同一 item）：显示将发生什么、发给谁、原文与 diff、为什么必须你批；动作 批准 / 改一改 / 驳回并说明（原因 chip：数据错 / 语气 / 太长 / 不合规 / 超范围）。

### 3.5 作战包与返工

作战包 = 执行摘要（谁做了什么、关键决策、风险、来源）+ 主文档 + 附件 + 教师 2 条待办 + 导出（v0.9.5 真 docx/xlsx）。
返工：原因 chip → 只重跑受影响任务（不整包重来）→ 版本 +1，其余交付物不动 → 负例写记忆。

## 4. 授权与信任

### 4.1 Autonomy L0–L3

| 级别 | 语义 | 默认用于 |
| --- | --- | --- |
| L0 旁观 | 只给建议与流程，不产出可发送内容 | 学生处分/敏感/涉隐私 |
| L1 草稿 | 自动产出草稿，对外动作必须人批（默认） | 家长沟通、成绩对外、教务上报 |
| L2 代办 | 内部产物自动完成、可撤回；对外仍走审批 | 教案/分析/练习/材料草稿 |
| L3 全权 | 低风险内部动作自动执行，只汇报 | 提醒/日程/进度整理 |

默认：总指挥只编排不代批对外；学情分析师/命题官/备课研究员 L2；家校沟通官 L1（发送恒需人批）；班务管家 L3（对外 L1），处分/考勤上报恒 L1。

### 4.2 授权矩阵与硬门

```
              取数  草稿  家长发送  成绩对外  处分/安全  公文回执
总指挥         L2    L2      —        —        L0        —
学情分析师     L2    L2      —        —        —         —
命题官         L2    L2      —        —        —         —
备课研究员     L2    L2      —        —        —         —
家校沟通官     L2    L1      L1硬门     —        —         —
班务管家       L3    L2      —        —        L0        L1
```

- 成绩对外：仅教师本人 L1，agent 只可准备。
- **硬门（不可上调、不可记忆豁免）**：家长发送、成绩与姓名同时对外、处分/心理/安全、对外承诺（时间/金额/范围）。
- 实现：规则表 + 审批门拦截 + 单测固化。

### 4.3 溯源展示

- 数字 chip 复用 v0.9.5 `md-cite`：hover/点开 = 值 + 来源（学校/考试/批次/时间）+ 哪个 agent 何时读取 + 是否降级。
- 作战包「来源与做法」折叠：数据源（seed/CSV/远端）、引用哪些卡/文档、谁写哪段、人工改动几处、AI 自评分数。
- 对外产物保留「AI 生成 · 人工复核」标识（沿用 v0.9 M3 责任边界）。

### 4.4 批评 / 表扬如何改变下次行为

- 表扬（👍 /「以后都这样」）→ `memoryStore` 语义偏好 `teacher.agent.<id>.pref.*`，置信度 0.6 起，下次同类直接生效（「先肯定再建议」→ 家校官默认结构改变）。
- 批评（驳回 chip /「太官方」「数字要带来源」）→ 负例偏好 + 生成前置约束 + 该 agent 同类推送静默 7 天；连续 3 次驳回 → 授权降一级，连续 3 次通过恢复。
- 可见可删：成员卡「已学偏好」可移除（防记错）；变更留记录。

## 5. 战队管理

### 5.1 成员卡

```
┌ 家校沟通官  L1（发送锁死）           状态：等你批 ┐
│ 擅长：家长信 · 通报 · 安抚话术 · 语气分级        │
│ 战绩：7 天 6 次产出 · 一次通过 5 · 驳回 1        │
│ 已学：先肯定后建议 / 不公开排名 [可删]           │
│ [调授权] [看最近 3 次产出] [暂停]                │
└───────────────────────────────────────────────────┘
```

字段：一句话职责 / 擅长 3 项 / 当前授权（按事项类型）/ 工具白名单摘要 / 近 7 天战绩 / 已学偏好 / 当前状态。

### 5.2 授权调整

滑杆 L0–L3 + 硬门小锁（不可越过）+ 变更记录 + 二次确认；按事项类型分别设置；调整即刻生效，并在下一条动态注明「按你 11-10 14:32 的授权执行」。

### 5.3 周报

每周一进战情台摘要（或周五下班前）：①授权使用（批/否/改）②战队产出（按 agent）③帮到你什么（采纳率、返工率、省时估算）④建议调整（如「家校官 3 次因语气被驳回，建议补偏好或降级」，一键采纳）。周报是授权复议，不是 KPI 榜。

## 6. 10 分钟演示脚本

设定：教师李建国（高一（3）班班主任 / 物理），演示日=家长会前 3 天；数据全用 seed（物理 82.4 / 数学 78.6 / 化学 80.2、作业完成率 93%、专注度 86、函数单调性 61%、12 所监测校）；`?demo=1` 冷启动。标注〔复〕复用、〔新〕v1.0 新建。

| 时间 | 画面 | 教师动作 | 台词要点 | 预期效果 | 设计点 |

## 7. 反模式与设计红线（5 条）

1. **不做通知中心**：无「全部已读」，每条信息必须带决策动作；推送有预算。
2. **不做仪表盘**：首页 ≤3 个数字、0 图表；数字只在支撑决策时出现。
3. **不做聊天换皮**：主入口不是输入框；对话只是插话通道，默认界面是待决策与动态。
4. **不重提示轻交付**：每次托管必须落可导出/发送的作战包；动态流不是业绩展示。
5. **不假装智能**：不伪造云端后台与真实发送、不隐藏 AI 生成与数据降级、不代做对外承诺、硬门不可上调。

## 8. 可直接拆的任务（里程碑）

- **M0–M1（5–7 天）**：InboxSurface + 战情条 + DecisionItem + decisionStore + P 公式 + 预算/时间窗 + 降级。验收：首屏 3 条决策 + 公式单测。
- **M2–M3（8–10 天）**：PlanConfirm + Mission + 动态流 + 暂停/撤回 + 审批门 + 授权硬门 + 溯源 + 偏好。验收：离开 90 秒回来有摘要；硬门不可绕过。
- **M4（3–4 天）**：交付物 + 成员卡 + 周报 + 移动 4 tab + 迁移/备份 + E2E。
