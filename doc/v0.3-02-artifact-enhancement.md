# v0.3 专项 ②：Artifact 增强

> 优先级：P1 ｜ 前置：v0.2（ArtifactApiAdapter 流式生成已交付）
> 目标：文档从「只能看」到「能带走、能回溯、能复用」——全格式导出、版本历史、模板库。

## 一、背景与目标

v0.2 后文档支持流式生成与在线编辑，但缺少三个高频能力：

1. **导出**：教师要把教案带进教室（打印/PDF），行政要发通知（Word）
2. **版本历史**：AI 重新生成或多次编辑后，旧版本丢失无法回溯
3. **模板库**：新建文档从空白开始，v0.1 已有的模板资产没有暴露给用户

## 二、现状与改动文件

| 现状 | 文件 | 改动 |
| --- | --- | --- |
| 文档仅在线渲染/编辑 | `src/apps/artifacts/ArtifactPanel.tsx` | 工具栏增加 导出/历史/模板 入口 |
| 无版本概念 | `src/stores/artifactStore.ts` | 增加 `revisions: {content, savedAt}[]` 与 `saveRevision/restoreRevision` |
| 模板仅 harness 内部使用 | `src/harness/scripts/artifacts.ts` | 导出 `listTemplates(role)` 供 UI 选择 |
| 无导出能力 | 新增 `src/lib/exporters.ts` | Markdown/Word/PDF 三种导出实现 |

## 三、技术方案

### 3.1 导出（零依赖）

`src/lib/exporters.ts`：

```ts
exportDoc(doc: { title: string; content: string }, format: 'md' | 'docx' | 'pdf'): void
```

- **Markdown**：`new Blob([content], {type:'text/markdown'})` + `URL.createObjectURL` + `<a download>`；
  文件名 `{title}.md`（标题做文件名安全字符替换）
- **Word**：doc 兼容 HTML（Office 可直接打开 .doc HTML 文件）：

```html
<html xmlns:o="urn:schemas-microsoft-com:office:office" xmlns:w="urn:schemas-microsoft-com:office:word">
<head><!--[if gte mso 9]><xml><w:WordDocument><w:View>Print</w:View></w:WordDocument></xml><![endif]-->
<meta charset="utf-8"><style>body{font-family:SimSun;font-size:12pt}</style></head>
<body>{renderMarkdown(content)}</body></html>
```

  以 `application/msword` Blob 下载为 `{title}.doc`。零依赖，样式保真度满足公文/教案需求。
- **PDF**：`window.print()` + 打印样式（`@media print` 隐藏工作台其余区域、仅打印文档容器）。
  实现方式：给文档容器加 `print-area` 类，全局 CSS `@media print { body * {visibility:hidden} .print-area, .print-area * {visibility:visible} .print-area {position:absolute; inset:0} }`。

### 3.2 版本历史

1. `artifactStore` 的 `ArtifactDoc` 增加 `revisions: { content: string; savedAt: number }[]`。
2. 快照时机：手动编辑保存（`updateContent` 时若与上次快照差异 > 50 字符则自动快照）、
   AI 重新生成前（`createPlaceholder` 时对同 goal 旧文档快照）。
3. 上限 20 份，超出丢弃最旧；随文档一起持久化到 LocalStorage。
4. UI：`ArtifactPanel` 工具栏「历史」→ 侧滑列表（时间 + 字数预览）→ 点击预览 → 「恢复此版本」。

### 3.3 模板库

1. `scripts/artifacts.ts` 导出 `listTemplates(role: RoleId): {id: string; title: string; kind: ArtifactKind; skeleton: string}[]`。
2. `ArtifactPanel` 空态与「新建」入口展示模板卡片（按当前角色过滤）；选择后 `createBlank(fromTemplate)`。
3. 模板骨架即 v0.1 的 FALLBACK 模板正文，用户可在其上编辑或让 AI「基于此模板填充」
   （发送 goal 时附带模板内容作为上下文，走既有 chat 链路）。

## 五、验收标准

1. 任意文档可导出 .md / .doc / PDF（打印预览），Word 用 Office/WPS 打开排版正常
2. 编辑文档保存 2 次后，历史列表有 2 条快照，恢复旧版本后内容与字数正确回滚
3. AI 重新生成同主题文档前，旧版本自动进入历史
4. 新建文档可选择角色模板，骨架正确填充；「基于模板填充」走 AI 生成且保留模板结构
5. 导出/历史/模板均不引入新 npm 依赖，主包 gzip 增量 ≤ 3KB

## 六、风险与对策

| 风险 | 对策 |
| --- | --- |
| Word HTML 在部分 Office 版本样式偏差 | 使用最保守内联样式（宋体/字号/加粗），不依赖复杂 CSS |
| 打印样式影响工作台其他区域 | print-area 方案用 visibility 隔离，验收覆盖「打印预览仅含文档」 |
| 快照过于频繁撑爆 LocalStorage | 差异阈值 + 20 份上限 + 字数压缩预览 |
