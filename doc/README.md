## 文档规范

- 统一模板：背景与目标 → 现状与改动文件 → 技术方案 → 任务拆解 → 验收标准 → 风险与对策
- 任务拆解标注优先级（P0/P1/P2）与依赖关系；验收标准可测试、可演示
- 保持轻量定位：方案不引入重依赖，标注对生产包体（当前 gzip 84KB JS）的增量预算
