# v0.5 路线图 · 真实数据接入与协同深化

> 基于 v0.4 交付现状制定。v0.4 已完成：Agent 多轮循环/并行/重试/组合剧本、
> 分享链接与批注评审、下发任务链（Mock）、导出增强（Word 封面/批注附录）、
> Playwright 3 条关键路径 + GitHub Actions CI + 包体预算门禁、
> vendor 拆分（主 chunk gzip 104KB → 56KB）、content-visibility 虚拟化、
> 弹层无障碍（Esc/焦点）、DataProvider 存储抽象、API Key 混淆落盘。
> Vitest 65 例 + E2E 3 例全绿。
> v0.5 主线：**真实数据接入 + 协同闭环 + Agent 工具生态 + 发布工程**。

## 背景与目标

v0.4 后产品已具备「多轮 Agent 执行 × 分享批注 × 任务下发 × CI 门禁」的完整骨架，
但距离可推广仍有四类差距：

1. **数据仍是 Mock**：学情/校情/区域指标全部来自静态 seed，简报与看板无法反映真实校情；
   v0.4 的 DataProvider 抽象只覆盖了「存储」，未覆盖「数据源」；
2. **协同是单机模拟**：分享链接靠 URL 压缩快照（无后端），批注无法回流给作者，
   下发任务链的状态流转是前端 Mock，缺少真实通知通道；
3. **Agent 工具面窄**：仅有学情查询/命制试题/文档生成等内置工具，缺课标检索、
   资源库引用、跨文档操作；长会话上下文无压缩策略，token 成本随轮次线性增长；
4. **发布工程欠账**：无容器化部署方案、无运行时监控、视觉回归与 i18n 为 v0.4 顺延项。

## 里程碑与优先级

### M1 · 真实数据接入（P0）

| 任务 | 说明 | 涉及文件 |
| --- | --- | --- |
| ① 数据源 DataProvider | 抽象 `SourceProvider` 接口（`getBriefing/getClassProfile/getRegionMetrics`），静态 seed 与远端 API 双实现，设置页可切换 | 新增 `harness/sources/`、`data/seed.ts` 改造 |
| ② 学情数据对接 | 对接校方成绩导出（CSV 上传解析 → 学情聚合），简报卡片由真实数据驱动 | 新增 `lib/csvImport.ts`、`BriefingPage` |
| ③ 看板真实指标 | 校情驾驶舱/区域看板接入 SourceProvider 远端实现（带缓存与降级：请求失败回落 seed） | `AlertBoard.tsx`、`RegionBoard.tsx` |
| ④ 数据新鲜度 | 简报/看板标注数据时间戳与来源；超过 7 天提示刷新 | `BriefingPage.tsx`、看板组件 |

依赖：① 是 ②③④ 的前置；② 可与 ① 并行开发（先做解析器）。

### M2 · 协同闭环（P0）

| 任务 | 说明 | 涉及文件 |
| --- | --- | --- |
| ① 分享短链服务 | proxy 增加分享端点（POST /v1/share 落 KV/SQLite，GET /s/:id 返回快照），URL 从 2KB 压缩串降为短链 | `proxy/server.mjs`、`lib/share.ts` 双模式 |
| ② 批注回流 | 分享视图批注写入后端；作者端「收到的批注」列表 + 一键定位到文档对应段落 | `ShareView.tsx`、`artifactStore`、`ChatPanel` 通知条 |
| ③ 任务链真实流转 | 下发任务接后端（局→校→教师三级状态机），教师完成回执自动上报；无后端时降级 Mock | `taskFlowStore.ts`、`TaskFlowBoard.tsx` |
| ④ 通知中心 | 侧栏增加通知入口：批注/回执/任务下发统一聚合，未读角标 | 新增 `NotificationPanel.tsx`、`Sidebar.tsx` |

依赖：① 是 ② 的前置；③ 独立（可先做前端状态机对齐后端协议）。

### M3 · Agent 工具生态（P1）

| 任务 | 说明 | 涉及文件 |

## 验收标准（可演示）

- [ ] 上传一份班级成绩 CSV，简报首卡基于真实数据生成薄弱点结论；
- [ ] 生成分享短链（≤30 字符），手机浏览器打开只读视图，批注后作者端收到通知并可定位段落；
- [ ] 局角色下发任务 → 校长确认 → 教师完成 → 局端看到回执，全链路状态正确；
- [ ] 对话发送组合任务，trace 显示课标检索工具调用；长会话（>20 轮）token 用量不再线性增长；
- [ ] CI 全绿：单测 + E2E + 视觉回归 + 包体门禁 + Lighthouse ≥85；
- [ ] `docker compose up` 一条命令拉起代理服务并完成一次真实对话。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 校方数据格式不统一 | CSV 解析器做列名模糊匹配 + 导入预览确认，失败给出可修正提示 |
| 短链服务被滥用 | 复用 v0.2 限额通道（per-IP + 日额），分享内容长度与频率双重限制 |
| 真实数据接口不稳定 | SourceProvider 全部带超时 + seed 降级，UI 标注「演示数据」 |
| 视觉回归误报多 | 截图前固定字号/数据档位，阈值放宽至 5%，首月仅告警不阻断 |
| 上下文压缩丢信息 | 摘要保留结构化结论（数据/决策），原文可展开回看；压缩前后各跑一次回归用例 |

## 版本节奏建议

- M1① + M3①（1 周）：数据源与工具抽象先行，决定后续形态；
- M2（1 周）：短链 + 批注回流 + 任务链，协同闭环成型；
- M1 其余 + M3 其余 + M4（1 周）：真实数据收尾、成本护栏、发布工程；
- M5（0.5 周）：安全加固，发布 v0.5。
