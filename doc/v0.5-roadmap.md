# v0.5 路线图 · 真实数据接入与协同深化

> 基于 v0.4 交付现状制定。v0.4 已完成：Agent 多轮循环/并行/重试/组合剧本、
> 分享链接与批注评审、下发任务链（Mock）、导出增强（Word 封面/批注附录）、
> Playwright 3 条关键路径 + GitHub Actions CI + 包体预算门禁、
> vendor 拆分（主 chunk gzip 104KB → 56KB）、content-visibility 虚拟化、
> 弹层无障碍（Esc/焦点）、DataProvider 存储抽象、API Key 混淆落盘。
> Vitest 65 例 + E2E 3 例全绿。
> v0.5 主线：**真实数据接入 + 协同闭环 + Agent 工具生态 + 发布工程**。

## 背景与目标

v0.4 后产品已具备「多轮 Agent 执行 × 分享批注 × 任务下发 × CI 门禁」的完整骨架，
但距离可推广仍有四类差距：

1. **数据仍是 Mock**：学情/校情/区域指标全部来自静态 seed，简报与看板无法反映真实校情；
   v0.4 的 DataProvider 抽象只覆盖了「存储」，未覆盖「数据源」；
2. **协同是单机模拟**：分享链接靠 URL 压缩快照（无后端），批注无法回流给作者，
   下发任务链的状态流转是前端 Mock，缺少真实通知通道；
3. **Agent 工具面窄**：仅有学情查询/命制试题/文档生成等内置工具，缺课标检索、
   资源库引用、跨文档操作；长会话上下文无压缩策略，token 成本随轮次线性增长；
4. **发布工程欠账**：无容器化部署方案、无运行时监控、视觉回归与 i18n 为 v0.4 顺延项。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 校方数据格式不统一 | CSV 解析器做列名模糊匹配 + 导入预览确认，失败给出可修正提示 |
| 短链服务被滥用 | 复用 v0.2 限额通道（per-IP + 日额），分享内容长度与频率双重限制 |
| 真实数据接口不稳定 | SourceProvider 全部带超时 + seed 降级，UI 标注「演示数据」 |
| 视觉回归误报多 | 截图前固定字号/数据档位，阈值放宽至 5%，首月仅告警不阻断 |
| 上下文压缩丢信息 | 摘要保留结构化结论（数据/决策），原文可展开回看；压缩前后各跑一次回归用例 |

## 版本节奏建议

- M1① + M3①（1 周）：数据源与工具抽象先行，决定后续形态；
- M2（1 周）：短链 + 批注回流 + 任务链，协同闭环成型；
- M1 其余 + M3 其余 + M4（1 周）：真实数据收尾、成本护栏、发布工程；
- M5（0.5 周）：安全加固，发布 v0.5。
