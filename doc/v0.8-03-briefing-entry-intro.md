# v0.8 增量优化 · 简报首次进入生成切入动画（交付说明）

> 本专项为 v0.8.2 交付后的小型优化（一项），随 v0.8.3 发布。
> 状态：✅ 已完成 · tsc 验证通过，无新依赖，纯 transform/opacity 动画（合成器友好），E2E / 视觉回归路径零影响。

## 背景与目标

v0.7 起简报页具备完整的滑卡批示体验，但用户（已看过操作引导的老用户）每次会话首次进入简报时，
页面从加载骨架屏直接切到卡组，缺少一个与「纸墨批阅」设计语言一致的开场仪式感。

本次为**首次进入简报**与**重新过一遍**增加一段切入动画，表现「今日简报卡牌正在生成」的过程：

1. **符合设计风格**：卡牌几何（圆角 28px / surface 底 / line 描边 / shadow-card）对齐卡组堆叠层，
   迸光配色取自设计系统四色（primary 靛蓝 / mint 绿 / amber 琥珀）；
2. **表现卡牌生成过程**：三张卡牌自右下依次飞入落叠，落卡迸光，顶卡星芒脉冲 + 微光扫过表达生成中；
3. **无文字**：全程不出现任何文案，动画自解释。

## 实现

### 改动一：切入动画组件（新建 `apps/briefing/BriefingIntro.tsx`）

| 项 | 说明 |
| --- | --- |
| 卡牌飞入 | 三张卡牌按 0 / 190 / 380ms 交错自右下飞入落叠（`intro-deal` 560ms，缓动对齐全局 `cubic-bezier(0.22,1,0.36,1)`），落定微倾角 -5° / 3° / 0° 经 `--intro-rot` CSS 变量注入；几何（inset / 尺寸 / 透明度）对齐真实卡组的堆叠三层 |
| 落卡迸光 | 每张卡飞入落定时刻（delay + 400ms）在右上角迸出一圈光晕扩散淡出（`intro-spark`），顶卡额外迸出三色碎粒（`intro-bit`，向量经 `--intro-bx/--intro-by` 注入） |
| 生成中表达 | 顶卡卡面为简报骨架条 + 底部生成区：星芒图标脉冲（`animate-pulse`）+ 斜向微光反复扫过（`intro-shimmer` 1.3s 循环） |
| 收场交棒 | 保底展示 1250ms（末卡落定 + 迸光收尾）后，若卡组就绪（`ready`，即 `loading=false`）则整体微缩淡出（`intro-out` 300ms）交棒给真实卡组的既有入场动画（`card-enter` stagger）；卡组未就绪（API 模式生成中）则微光循环等待，就绪后即收场 |
| 性能与可达性 | 纯 CSS keyframes（transform/opacity），无 JS 动画帧、无新依赖；`pointer-events-none` 不拦截交互；`prefers-reduced-motion` 下跳过动画直接交棒；`aria-hidden` 对读屏隐藏 |

### 改动二：接入与门控（`apps/briefing/BriefingPage.tsx` + `tailwind.config.js`）

| 项 | 说明 |
| --- | --- |
| 播放门控 | 会话级模块标记 `introPlayed`（普通进入每次页面会话至多播一次）+ `guideSeen` 门控：首次使用者首进弹操作引导（既有 v0.3 行为），不叠加动画；`INTRO_ELIGIBLE` 为函数，在播放入口实时判定弱动效偏好与引导状态 |
| 舞台接管 | 动画期间接管卡片舞台（不渲染骨架屏 / 卡组），避免「生成动画 → 骨架屏 → 卡组」三段跳；淡出后真实卡组以既有 `card-enter` 入场，观感连续 |
| 重播接线 | 「重新过一遍」（批示完成空态 / 专注模式总结层）统一收敛为 `replayDeck`：清保留层 → 重置卡组 → 重播切入动画 → 重载卡组；动画期决策栏不渲染与批示守卫同样生效；普通在工作台 ↔ 简报往返仍不重播 |
| 交互保护 | 动画期间决策栏不渲染、`handleDecide` 增加 `intro` 守卫，防止键盘 / 按钮批示到未展示的卡片；`introPlayed` 在 effect 中置位，兼容 StrictMode 双挂载 |
| 动画帧注册 | `tailwind.config.js` 新增 `intro-deal` / `intro-shimmer` / `intro-out` / `intro-spark` / `intro-bit` 五组 keyframes（0% 帧透明 + `both` 填充，延迟期内不可见） |

### 兼容性

- **E2E / 视觉回归零影响**：E2E 与视觉基线用例均清空 LocalStorage → `guideSeen=false` → 动画不播，关键路径与 briefing.png 基线不受干扰；
- **首次使用者不受打扰**：未看过操作引导的用户首进仍是引导弹窗；同会话内刚看完引导再「重新过一遍」也可正常播放；
- 移动端同样生效（纯展示层动画，不涉及 v0.8.2 桌面端保留层门控）。
