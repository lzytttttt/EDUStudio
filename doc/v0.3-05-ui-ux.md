## 1. 字体大小调整

**入口**：设置弹层 → 界面字号（小 / 标准 / 大 / 超大 四档），即时生效并持久化。

**实现**：
- `settingsStore.fontSize`（`small | medium | large | xlarge`），随 `edustudio:settings` 持久化；
- `main.tsx` 订阅 store，同步到 `<html data-font="...">`；
- `index.css` 定义 `--content-fs` 变量（13px / 14px / 16px / 20px），仅作用于**阅读区**：
  - `.chat-bubble`（对话气泡）
  - `.md-body`（文档预览，内部标题/表格改用 em 相对尺寸，随档位整体缩放）
  - `.doc-editor`（文档编辑器，0.85×）
  - `.chat-input`（对话输入框）
- 布局骨架（侧栏/顶栏/按钮）不受影响，避免三栏错位。

### 超大档（xlarge）· 高龄用户适配

- 阅读字号 20px；Agent 轨迹（`.agent-trace`）内固定小字号统一放大至 15px，保证可读；
- **次要信息简化**：打 `.minor-info` 标的元素在超大档下整体隐藏，聚焦核心内容：
  - 简报页：日期、键盘操作提示行；卡片置信度圆点、来源行
  - 工作台：侧栏模式小字、会话时间戳、收藏来源、文档日期、角色副标题
  - 对话：任务完成卡的剩余卡片提示、trace 的「查看返回数据」入口
  - 文档：底部元信息（来源/字数）、导出菜单格式提示、版本历史时间与字数
- 设置弹层文案明示该行为，用户可随时切回标准档恢复完整信息。

## 3. 移动端优化

| 项 | 实现 |
| --- | --- |
| iOS 输入聚焦自动放大 | `@media (pointer: coarse)` 下 `.chat-input` 字号 ≥16px |
| 安全区避让（刘海屏/手势条） | `.pb-safe` 工具类 + 简报决策栏 `pb-[max(28px,env(safe-area-inset-bottom))]` |
| 点击高亮闪烁 | `html { -webkit-tap-highlight-color: transparent }` |
| 点击 300ms 延迟 | `button/a { touch-action: manipulation }`（保留捏合缩放） |
| 橡皮筋滚动 | `body { overscroll-behavior-y: none }` |
| 视口适配 | `viewport-fit=cover`（v0.2 已有，本版配合安全区生效） |

既有响应式保持：<1280px 右栏抽屉、<768px 单栏 + 顶栏导航、简报滑卡触控。
