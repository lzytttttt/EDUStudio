# v0.9.4-02 · 空间任务台体验打磨（增量）

> v0.9.4 增量里程碑（不升版本号，同 v0.9.2-01 先例）。
> 背景：Loom 空间任务台交付后的第一轮真实使用反馈，集中在「占屏比例、标题口径、大字档位可读性、画布反馈」四点。
> 状态：✅ 已完成 · 单测 + tsc + E2E + 包体门禁全绿，零新依赖。

## 一、背景与目标

v0.9.4 交付「空间任务台」（`doc/v0.9.4-01-loom-implementation.md`）后，四项体验问题按优先级排列：

| # | 问题 | 影响 |
| --- | --- | --- |
| 1 | 画布高度固定 300px，不能按任务多少调整 | 任务多时反复缩放/平移才能看全；任务少时浪费中栏空间 |
| 2 | 画布标题沿用业务措辞（"本周管理任务"等） | 与「空间任务台」的产品语言不一致，容易被误读成待办清单 |
| 3 | 大字档位（≥18px）下节点卡内容截断、状态行被挤出 | 大字档位是教育场景刚需（教师端投屏/家长端阅读），画布不可读即不可用 |
| 4 | 画布反馈只有单一 toast，成功 / 失败同色、互相覆盖 | 连线被拒（成环）等关键反馈容易被忽略或误读 |

## 二、改动项与实现

### ① 画布高度可拖拽（最大占中栏 80%）

- `uiStore` 新增 `loomHeight`（px，默认 300）与 `setLoomHeight`（内存态，不持久化——每次进入工作台回到默认高度，避免上一轮演示的极端比例留在下一次）；
- 画布面板顶部新增纵向拖拽条（`data-testid="loom-resize"`，`cursor-row-resize`）：向上拖增大、向下拖缩小；
- 边界：最小 **180px**，最大 **中栏高度的 80%**（实时读取父容器高度计算，窗口 resize 后自然收敛）；
- 双击拖拽条重置为默认 300px；
- 沉浸态（`loomImmersive`）下不显示拖拽条（此时已占满中栏，拖动入口由沉浸切换按钮承担）。

### ② 画布标题统一为「xx画布」

`loomStore.ROLE_BOARD_TITLE` 三处同一口径（原为"今日教学任务 / 本周管理任务 / 区域协同任务"）：

| 角色 | 原标题 | 新标题 |
| --- | --- | --- |
| teacher | 今日教学任务 | 教学画布 |
| schoolAdmin | 本周管理任务 | **管理画布**（反馈明确要求） |
| bureau | 区域协同任务 | 区域画布 |

> 同步另两个角色的原因：画布标题是同一视觉体系里的并列项，只改一处会显得口径分裂；如只需保留「管理画布」，回退另两行即可。
> 画布空状态引导语「把今天的任务摊开来处理」保留（属引导文案，不属标题）。

### ③ 大字档位下的节点内容

现状根因：节点卡为固定 `220×96`，标题 `truncate` 单行、描述 `line-clamp-2`，字号随根字号放大后必然溢出 / 截断。

- **卡片高度改为 `min-height` 自适应**：内容（放大后的标题 / 描述 / 状态行）撑多高就多高，不再被 96px 裁掉；
- **大字档位放宽行数**（`src/index.css`，仅 `html[data-font='xlarge']` 生效）：
  - 标题 `.loom-node-title`：单行截断 → 两行省略；
  - 描述 `.loom-node-desc`：两行省略 → 三行省略；
- **次要信息不跟随放大**：类型标签 / 状态行 / 展开按钮（`.loom-node-meta`）在大字档位固定为 12px——它们是辅助信息，保持紧凑可让卡片高度增长可控（实测约 96 → 112px），同时正文依旧跟随全局字号放大；
- **连线锚点取舍**：几何仍按逻辑尺寸 `220×96` 计算（`loomGeometry`），大字档位卡片增高后连线锚点位于卡片上部约 1/3 处——视觉可接受；如需像素级贴合需引入节点实测尺寸，列入后续候选（不在本增量）。

### ④ 画布通知（toast）分级与堆叠

- `uiStore` 新增极简通知队列：`loomToasts: { id, kind, text }[]`、`pushLoomToast(kind, text)`（3.2s 自动消失，最多同时 3 条）、`dismissLoomToast(id)`；
- 画布顶部居中堆叠渲染（替代原单条 `hint`），分级配色：
  - `success`（mint）＝已连接 / 操作完成；
  - `error`（danger）＝成环 / 重边 / 自环等被拒；
  - `info`（中性）＝从画布移除等状态说明；
- 文案可换行、最大宽度约 20rem，大字档位下自然增高不裁切；
- 新增反馈点：从画布移除任务 / 删除模块 → `info`「已从画布移除，任务与产出保留」/「模块已删除」，补上原本无反馈的破坏性操作。

## 四、验收标准

1. **高度可调**：拖拽条向上拖动时画布增高，最大不超过中栏高度的 80%（窗口高度变化后仍成立）；向下拖动不小于 180px；双击恢复 300px；沉浸态无拖拽条；
2. **标题口径**：三个角色画布标题分别为「教学画布 / 管理画布 / 区域画布」，全站无「本周管理任务」残留；
3. **大字档位可读**：字号最大档（≥18px）下，节点标题可显示两行、描述三行，状态行完整可见且卡片无内容溢出（`scrollHeight <= clientHeight`）；
4. **通知分级**：连线成环显示 danger 文案；连线成功显示 mint 文案；移除节点显示中性文案；连续操作时最多并列 3 条，不互相覆盖；
5. **质量门禁**：`npm test`、`npm run build`、`npm run e2e`、`check:budget` 全绿，零新依赖。

## 五、风险与对策

| 风险 | 对策 |
| --- | --- |
| 拖拽高度与窗口缩放冲突 | 上限按父容器实时高度计算（非缓存值）；`resize` 时若当前高度超限则自动收敛 |
| 高度状态未持久化，用户觉得"记不住" | 有意为之（演示场景优先可预期）；如后续需要可并入 `settingsStore` 持久化 |
| 大字档位卡片增高导致连线锚点偏上 | 本增量接受（锚点位于卡片上部 1/3）；如需精确贴合，后续引入节点实测高度 |
| toast 定时器在单测中残留 | 队列状态在 `uiStore`（可断言），定时器仅负责移除；单测不依赖真实计时 |
| 标题口径改动影响既有 E2E / 基线 | E2E 断言一律走 `data-testid`（不依赖标题文案）；视觉基线中标题变化 → 重生成基线 |

## 六、交付记录（2026-09-11）

- **① 高度可拖拽**：`uiStore.loomHeight` + 纯函数 `clampLoomHeight(height, parentHeight)`（180px ~ 中栏 80%）；面板顶部拖拽条（`data-testid="loom-resize"`，`cursor-row-resize`），双击复位 300px；窗口 resize 后自动收敛；懒加载占位高度与面板一致（避免加载瞬间跳变）；
- **② 标题口径**：新增 `roleBoardTitle(role)`（教学 / 管理 / 区域画布），渲染与 `migrate` 共用——**历史数据里的旧标题在加载时归一化**，老用户画布同样显示新口径（E2E 用例 ⑧ 暴露的连带修复）；
- **③ 大字档位**：节点卡改 `min-height` 自适应；`index.css` 增加 `html[data-font='xlarge']` 规则（标题两行、描述三行、`.loom-node-meta` 固定 12px），卡片高度增长可控（约 96 → 112px）；
- **④ 通知分级**：`uiStore.loomToasts` 队列（success mint / error danger / info 中性，≤3 条并列，3.2s 自动消失）；画布顶部堆叠渲染替代原单条 `hint`；「从画布移除 / 删除模块」补上反馈；
