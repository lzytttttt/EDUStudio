# v0.9.3 路线图 · 演示演出打磨：让「看得见的聪明」不掉帧、不翻车

> 依据 2026-09-10 全项目演出审阅结论（现场演示 + 60s 宣传片双线）制定。v0.9.2 交付现状：
> 单测 232 例 + tsc + E2E + 视觉回归 + 包体门禁全绿。v0.9.3 主线：**不重设计、不换风格，
> 只修演示主链路的断点、节奏与掉帧——把 Agent 的可见过程真正让人看见、看顺、看完**。

## 背景与目标

教育者视角的首屏评审（v0.9.2）之后，演示视角审计又发现四类「现场会翻车」的问题：

1. **主演出被藏起来（P0）**：右栏按角色默认 tab 为「工作台 / 下发」（v0.9.2 P0-B），
   Agent 生成文档时最出彩的 Markdown 流式生成停留在「文档」页签内，观众看不到；
2. **输入态被快捷键劫持（P0）**：简报页在 window 监听 ←/↑/→，编辑卡片正文或弹窗输入时
   按方向键会直接跳过 / 收藏 / 采纳卡片，演示中误操作不可挽回；
3. **日期与新鲜度在演示日失真（P0）**：简报头日期硬编码，「演示数据」基线固定 2026-09-01，
   超过 7 天后默认常驻「建议刷新」，观众容易误读为产品数据过旧；
4. **流式演出掉帧（P0/P1）**：文档每个 chunk 触发全量 Markdown 重渲 + 全 store 订阅；
   对话区每 chunk 平滑滚动抢占视口——长内容演示时肉眼可见卡顿与滚动抖动。

另有一组 P1/P2 改进：技能沉淀高光被埋、演示向导入口与失败反馈、首进引导与切入动画互斥、
StrictMode 开发态双跑简报生成、输入类持久化逐键写盘、未使用依赖、宣传片工程化与物料一致性。

v0.9.3 明确**不做**（记录决策，避免反复）：整体 Redesign、设计 token 调整、引入路由 /
状态库 / 虚拟列表依赖、重写 Markdown 渲染器、LLM 版记忆与自评（延续二期候选）。

## 验收标准

1. **文档即见**：教师 Mock 模式发送「针对高一（3）班函数单调性薄弱点出分层练习」，无需点击任何 tab，右侧文档面板自动可见且正文逐字增长；
2. **输入无误触**：在卡片正文编辑态与「重新生成」弹窗输入框连按 ←/↑/→ 各 20 次，决策计数与卡片状态零变化；
3. **日期与新鲜度**：全新浏览器（清空 `edustudio:` 存储）登录后，简报日期为当天；seed 模式不出现「建议刷新」；`dataSource=remote` 超 7 天与 CSV 旧数据仍正确提示；
4. **不掉帧**：2000 字文档完整流式期间，Performance 面板无 >50ms long task，滚动位置不被强制拽回底部；
5. **节奏正确**：演示向导三幕轨迹顺序为「… → 已沉淀 / 已进化 → 完成」；连续演示 3 次后开场记忆注入不超过 1 行；
6. **首进可控**：一键「演示直达」≤2 次点击进入简报；冷启动引导关闭后能看到卡牌切入动画；
7. **质量门禁**：`npm test`、`npm run build`（单测 + tsc）、`npm run e2e`、`check:budget` 全绿；包体不超过 270KB gzip（或按先例重校并在本文件记录）。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 自动切「文档」tab 与 v0.9.2 角色主工作台默认激活冲突 | 仅「新文档占位」触发一次；默认 tab / 手动选择不回退；提供返回主工作台提示 |
| 节流导致流式观感「跳字」 | 100ms 窗口 + 尾帧补齐，`finalize` 全量渲染；开关量级可调并写入单测 |
| 键盘守卫误伤全局快捷键 | 只屏蔽可编辑元素与弹层打开态；正常态 ←/↑/→ 行为逐字节不变 |
| seed 新鲜度调整影响「较旧数据」演示卖点 | 保留 remote / CSV 两条真实链路演示 freshness；单测固定 now 固化 `isStale` |
| 持久化 debounce 丢数据 | 关键节点（finalize / 切换文档 / 页面隐藏 / 退出前）强制 flush，并加往返单测 |
| 视频入库增大仓库体积 | 仅入库工程源；mp4 / wav 走 LFS 或 Release 附件；npm scripts 保证可复渲 |

## 关键决策记录

1. **P0 修「演出断点」优先于 P2 打磨**：可见性、误触、日期、掉帧四项直接决定演示成败，先行合并；
2. **自动切 tab 只切一次**：不为新演出牺牲 v0.9.2 已交付的「角色主工作台默认激活」决策，二者以「占位触发 + 可返回」共存；
3. **性能治理不加库**：沿用 rAF 节流 + 选择器订阅 + `React.memo` + 既有 `content-visibility`，不引入虚拟列表或性能监控依赖；
4. **宣传片零生产影响**：`video/` 不进入构建与包体预算，仅提供 npm 脚本与物料一致性约束；
5. **不做清单**：整体重构 / 换路由与状态库 / 重写 Markdown 渲染器 / LLM 版记忆与自评 / 云端同步。
