# v0.4 路线图 · 协作深化与工程化

> 基于 v0.3 交付现状制定。v0.3 已完成：角色深化（出题工作台/校情驾驶舱/区域看板）、
> Artifact 增强（导出/版本历史/模板库）、偏好个性化、UI/交互优化（字号/引导/移动端）、
> Vitest 单测 39 例 + build 双闸门。
> v0.4 主线：**Agent 能力升级 + 协作分享 + E2E 工程化 + 性能治理**。

## 背景与目标

v0.3 后产品已具备「三角色 × 对话执行 × 文档产出 × 数据看板」的完整闭环，但存在四类短板：

1. **Agent 能力天花板**：编排为「单轮 plan → 单工具 → 文档」线性流，不支持多轮工具循环、
   工具并行与流式工具参数，复杂任务（如「先查学情再出题再写教案」）需拆成多次对话；
2. **协作缺失**：文档只能本机导出，无分享/批注/协同评审路径，校长→教师、局→校的下发链路断裂；
3. **工程化欠账**：E2E 测试未落地（v0.3 因浏览器下载环境限制顺延），CI 缺失，包体主 chunk 292KB
   （gzip 100KB）仍有拆分空间；
4. **数据孤岛**：seed 静态数据写死，无法对接真实校情/区域数据源。

## 里程碑与优先级

### M1 · Agent 能力升级（P0）

| 任务 | 说明 | 涉及文件 |
| --- | --- | --- |
| ① 多轮工具循环 | Orchestrator 支持 `plan → tool → 观察 → 再 plan` 循环（上限 5 轮），trace 记录每轮决策 | `harness/agent/Orchestrator.ts`、`MockOrchestrator.ts` |
| ② 工具并行执行 | plan 中多个独立 tool 步骤 `Promise.all` 并行，trace 标注并行组 | 同上 |
| ③ 流式工具参数 | function-calling 的 `arguments` 分片聚合后执行（当前已支持分片，补聚合边界测试） | `harness/llm/adapter.ts` |
| ④ 任务重试与断点 | 失败步骤可单独重试；会话条目增加 `retry` 动作 | `stores/chatStore.ts`、`ChatPanel.tsx` |
| ⑤ 组合任务剧本 | 新增「查学情→出题→写教案」组合剧本（Mock 模式演示多轮循环） | `harness/scripts/agent.ts` |

依赖：① 是 ②④⑤ 的前置；③ 独立。

### M3 · E2E 与 CI 工程化（P1，v0.3 顺延项）

| 任务 | 说明 |
| --- | --- |
| ① Playwright 接入 | `@playwright/test` + chromium；3 条关键路径：登录→简报→采纳→工作台、出题→工作台联动、文档导出 |
| ② CI 流水线 | GitHub Actions：`vitest → tsc → build → playwright`，PR 门禁 |
| ③ 包体预算门禁 | CI 校验主 chunk gzip ≤ 110KB、总 JS gzip ≤ 230KB，超限失败 |

> 环境备注：Playwright 浏览器下载约 120MB，需在具备网络的环境执行
> `npx playwright install chromium`；本仓库内先提交配置与用例，CI 环境完成安装。

## 验收标准（可演示）

- [ ] 对话发送「先查高一（3）班学情，再出分层练习，最后写教案」，Agent 自动多轮完成，trace 显示 ≥2 次工具调用；
- [ ] 文档可生成分享链接，新标签页打开为只读视图，校长角色可添加批注；
- [ ] `npm run e2e` 本地跑通 3 条关键路径；CI 全绿并执行包体门禁；
- [ ] 主 chunk gzip ≤ 110KB；Lighthouse 移动端 Performance ≥ 85；
- [ ] 键盘可完成「登录→简报处理→工作台出题→导出」全流程（无鼠标）。

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 多轮循环导致 token 成本失控 | 轮次上限 + 每轮上下文裁剪（只保留最近 2 轮工具结果） |
| 分享链接内容超 URL 长度限制 | 压缩 + 截断保护，超长降级为「导出文件分享」提示 |
| Playwright 在 CI 环境不稳定 | 用例加 `retries: 1`；关键断言用 data-testid 而非文本 |
| 包体门禁误伤正常迭代 | 预算阈值留 10% 余量，超限先告警后失败（两档） |

## 版本节奏建议

- M4 其余 + M5（0.5 周）：收尾治理，发布 v0.4。
