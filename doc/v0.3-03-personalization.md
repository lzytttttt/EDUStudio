# v0.3 专项 ③：记忆与个性化

> 优先级：P2 ｜ 前置：v0.2（真实 system prompt 注入链路已交付）
> 目标：让 AI「记得你是谁」——称呼/学段/常用场景偏好注入 system prompt，快捷指令可自定义。

## 一、背景与目标

v0.2 后真实模型对同一角色所有用户输出同质化。教师张老师与李老师得到的教案风格一致，
每次都要在对话里重复「我是初中物理老师」「按 40 分钟课堂设计」。本专项把这类稳定偏好
沉淀为用户画像，注入每次请求的 system prompt。

## 三、技术方案

### 3.1 偏好模型

```ts
interface UserPreferences {
  nickname?: string            // 称呼，如「张老师」
  stage?: string               // 学段学科，如「初中物理」
  style?: string               // 风格偏好，如「简洁务实，少用套话」
  scenes?: string[]            // 自定义快捷指令（覆盖 SCENES 默认值）
}
```

### 3.2 注入点

`roles/index.ts`：

```ts
export function buildSystemPrompt(preset: RolePreset, p?: UserPreferences): string {
  if (!p) return preset.systemPrompt
  const lines = [
    p.nickname && `用户称呼：${p.nickname}，回复时自然使用该称呼。`,
    p.stage && `用户背景：${p.stage}。`,
    p.style && `表达偏好：${p.style}。`,
  ].filter(Boolean)
  return lines.length ? `${preset.systemPrompt}\n\n【用户偏好】\n${lines.join('\n')}` : preset.systemPrompt
}
```

- `Orchestrator.runTask` 与 `runPlanJsonFallback` 的 system 消息改用 `buildSystemPrompt`
- `ArtifactApiAdapter.generate` 同样注入（文档风格个性化）
- Mock 模式不受影响（剧本驱动）

### 3.3 快捷指令自定义

- `ChatInput.tsx` 的 SCENES 改为默认值；`settingsStore.preferences.scenes` 非空时覆盖
- chips 末尾固定「+ 管理」项 → 弹出编辑列表（增删、拖拽排序可后置到 P2 收尾）

## 五、验收标准

1. 设置页填写「称呼：张老师 / 背景：初中物理」后，教师角色对话回复自然使用称呼且内容贴合初中物理
2. 生成的教案文档风格与「表达偏好」一致（如要求简洁则无套话堆砌）
3. 清空偏好后行为与 v0.2 一致（回归无差异）
4. 快捷指令 chips 可增删，刷新后保留；点击行为与原 SCENES 一致
5. 偏好仅存 LocalStorage，不随对话历史进入 trace 展示

## 六、风险与对策

| 风险 | 对策 |
| --- | --- |
| 偏好注入导致 prompt 超长 | 偏好字段限长（每项 ≤ 40 字），注入前截断 |
| 用户填写矛盾偏好 | 表单提示语引导；不做自动消解 |
| Mock/API 行为差异感知 | Mock 模式设置页标注「偏好仅 API 模式生效」 |
