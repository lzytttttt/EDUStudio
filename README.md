## 项目定位

通用 Agent Harness（Codex / CodeBuddy 类）对教育从业者太臃肿、成本高；
智教工坊（EDUStudio）以 **解耦 Harness + Mock 兜底 + DeepSeek 级低成本模型** 的模式，
构建开箱即用、离线可演示的教育工作台：登录即批阅，批示即立项，落章即留痕。

| 维度 | 通用 Agent Harness | **EDUStudio** |
| --- | --- | --- |
| 部署形态 | 需本地运行时 / 服务端 | **纯前端 SPA**（可本地部署） |
| 模型成本 | 受限于供应商 | **自主可控**，模型自选 |
| 演示稳定性 | 依赖网络与 Key | **Mock 兜底**，离线可演示，零翻车 |
| 教育场景贴合 | 通用提示工程 | **三角色剧本 + 数据上下文层 + 自进化技能** |
| 离线能力 | 弱 | **登录即用、LocalStorage 全量持久化** |
| 端到端体验 | 命令行 / IDE | **三屏流程**：登录 → 今日简报 → 工作台 |

## 三屏流程

EDUStudio 的产品形态是一条「**收件 → 批阅 → 处理**」的暗线：登录身份，简报滑卡盖章，工作台落地执行。

| 阶段 | 形态 | 关键能力 |
| --- | --- | --- |
| **登录** | 账号密码式正式页面，背景动效呼应「卡片简报 + 工作台」 | 三角色切换（教师 / 校管 / 教育局）、Mock ↔ API 模式切换、字号 12–22px 拖拽全局缩放 |
| **今日简报** | 卡片流首页，六类卡片（洞察 / 决策 / 创作 / 待办 / 数据 / 提问） | 拖拽 ← 跳过 / ↑ 收藏 / → 采纳，**真实落章动效**（双线印面 + SVG 印泥纹理 + 砸下回震），**v0.8.2 保留卡物理动效**，**v0.8.3 首进生成切入动画**，**v0.8.4 自定义重新生成**，**v0.9 导入文档 + 卡组周轮换** |
| **工作台** | 三栏布局：任务 / 对话 / Artifact | Agent 执行轨迹（Plan → Tool Call → Result → Reflect → Done）、命中技能徽标、自研 Markdown 渲染 |

把「工程师视角」换成「教育者的工作记忆视角」——不重设计、不换风格，只动信息架构与文案：

## v0.9.1 新特性 · 记忆分层与产出自评闭环

> 小型版本（4 个里程碑），随 v0.9.1 发布。
> 状态：✅ 已完成 · 单测（214 例，+33）+ tsc 验证通过，零新依赖。

让 AI「**记得你、评估自己、越用越懂你**」——记忆自动收割、偏好自动注入、产出自我评估，用户全程无感：

- **记忆分层存储（M1）**：L2 情景记忆（时间 / 角色 / 目标 / 结果，环形上限 200 条）+ L3 语义偏好（键值 + 置信度），单键 `edustudio:memory` 本地持久化并纳入备份白名单，按角色前缀隔离（教师记忆不进入教育局会话）；
- **产出自评（M2）**：文档生成完成后按类型规则评分（0-10 分 + 逐项检查 + 可执行建议，零 LLM 成本），界面诚实标注「AI 自评 · 仅供参考」，支持一键重新自评；
- **偏好注入（M3）**：对话系统提示注入「场景记忆 + 用户偏好」段（无记忆时与现状逐字节一致）；简报卡组在历史决策 / 收藏之上叠加语义偏好排序（收藏 > 偏好 > 默认，跳过仍沉底）；Mock 模式以 reflect 事件展示注入内容；
- **反馈闭环（M4）**：导出（编辑过 → 修改后采纳 / 未编辑 → 采纳）、文档「符合 / 不符合预期」反馈、简报卡片收藏 / 采纳——全部自动写入记忆并提炼偏好（出题数量 / 课时分钟 / 导出格式 / 负例回避）。

> 详见 [doc/v0.9.1-roadmap.md](./doc/v0.9.1-roadmap.md)。

## v0.9.0 新特性 · 信任与健壮性

> 主线版本（8 个里程碑），随 v0.9.0 发布。
> 状态：✅ 已完成 · 单测（181 例，+34）+ E2E（9 用例）+ 视觉回归（clock 固定日期）+ 包体预算全绿，零新依赖。

让产品从「可演示」走向「敢托付」——修复 Agent 主路径接线缺口、补数据安全网、立决策责任边界：

- **function-calling 接线（M1）**：`tools` 定义随请求体下发（v0.9 前从未进入请求体，API 模式任务型目标 100% 走 Plan-JSON 降级）；tool_calls 分片累积 / 并行执行 / 失败降级链路自此真正生效；
- **数据安全网（M2）**：设置页「数据备份」——一个 JSON 文件救所有本机数据（导出二次确认 / 恢复覆盖前确认 / 键名白名单跨版本兼容）；常驻明示「所有数据仅保存在本机浏览器，不会上传」；
- **决策责任边界（M3）**：简报页常驻「AI 生成内容仅供参考，采纳前请人工复核」，产出物头部同款提示，首次引导同步建立预期；
- **Mock 边界标识（M4）**：演示模式全局徽标 + 会话横幅，明示「内置剧本，非真实 AI」；
- **导航与返回键（M5）**：浏览器返回键不再退出站点（pushState/popstate 历史集成），移动端顶栏「← 简报」明确返回入口；
- **导入文档化（M6）**：全角色统一「导入文档」——.csv/.txt/.md 原文作为附件材料直通 LLM 上下文（含用途与指令输入框、长度上限截断、已导入回看/删除）；卡组按周粒度轮换保持新鲜感；
- **诊断打磨（M7）**：连接错误分类提示（断网跨域 / Key 无效 / 地址错误）、E2E 去硬编码、token 预算文案标注「约数仅统计输出」、Key 存储措辞审查（混淆非加密）；
- **质量与发布（M8）**：单测 +34 例（tools 请求体 / 备份往返 / 错误分类 / 附件注入 / 卡组周派生），E2E clock 固定日期对齐派生卡组，包体 266KB / 270KB 门禁通过。

## v0.8.4 新特性 · 简报自定义重新生成

> 小型优化（一项），随 v0.8.4 发布。
> 状态：✅ 已完成 · 单测（157 例，+8）+ tsc 验证通过，零新依赖。

简报页顶栏新增「重新生成」入口：悬浮弹窗表达「想要什么样的简报」，确认后按当前模式重载卡组：

- **提示词**：一句话定制（≤200 字，仅 API 模式生效），如「多关注物理学科薄弱点，语气务实」；
- **简报种类**：六类卡片多选（洞察 / 决策 / 创作 / 待办 / 数据 / 提问），不勾选 = 不限；Mock 模式按种类过滤静态剧本；
- **参考资料**：真实数据上下文（按角色命名）/ 历史决策 / 收藏卡片三段开关（API 模式注入生成上下文）；
- **高级自定义**：卡片数量（3-10，默认 5-7）、内容风格（简洁扼要 / 详细展开 / 数据导向）、交互卡片（图表 / 选项 / 待办）、生成参数（超时 6-30s、重试 1-3 次，均有 clamp 边界）；
- **偏好记忆**：选项随 LocalStorage 持久化，下次打开回填，刷新 / 重播同样生效；确认后清空决策重播切入动画，生成失败仍走「重试 + Mock 兜底」。

## v0.8.3 新特性 · 简报卡牌生成切入动画

> 小型优化（一项），随 v0.8.3 发布。
> 状态：✅ 已完成 · tsc 验证通过，无新依赖，纯 transform/opacity 动画。

已看过操作引导的用户**首次进入简报**与批示完成后**重新过一遍**时，播放一段与「纸墨批阅」设计语言一致的切入动画，
表现**今日简报卡牌正在生成**的过程（全程无文字）：

- **卡牌飞入落叠**：三张卡牌自右下依次飞入，落定微倾角交错，几何对齐真实卡组的堆叠三层；
- **落卡迸光**：每张卡落定瞬间右上角迸出一圈光晕，顶卡额外迸出三色碎粒（靛蓝 / 绿 / 琥珀）；
- **生成中表达**：顶卡星芒脉冲 + 斜向微光反复扫过——API 模式卡组生成较慢时持续循环等待，不闪骨架屏；
- **无缝交棒**：卡组就绪后整体微缩淡出，真实卡组以既有入场动画接棒，观感连续。

> 门控：普通进入每次会话至多播一次，「重新过一遍」总是重播；首次使用者首进仍为操作引导弹窗（不叠加）；`prefers-reduced-motion` 下跳过。

## v0.8.2 新特性 · 简报保留卡物理动效

> 小型优化（用户反馈一项），随 v0.8.2 发布。
> 状态：✅ 已完成 · 单测（149 例，+2）+ tsc 验证通过，无新依赖。

v0.7 的滑卡批示体验中，盖章后的卡片随离场动画**直接飞出消失**，带来两个问题：
批示缺少「留痕」仪式感、误操作挽回成本高。v0.8.2 让盖章卡**不消失**：

- **保留显示**：盖章后卡片以「拖拽末位置 + 飞出偏移」为起点进入物理运动，与 v0.7 离场动画无缝衔接；
- **物理运动**：单一 rAF 循环驱动全部保留卡 —— **无重力，仅空气阻力**（速度 / 角速度指数衰减）+ 四向等弹性边界碰撞反弹（0.6）；
- **缩小与半透明**：飞行途中 850ms ease-out 收缩至 0.55 倍、320ms 渐显至 0.55 透明度后定格；
- **盖章定格**：保留卡持续展示决策印章（跳过 / 收藏 / 采纳三色印面），「已盖章」一目了然；
- **拖回重新批阅**：点击 / 拖拽保留卡即可取回，**撤回决策**（收藏联动移除、计数回退）并置顶为当前卡，可修改选项 / 待办 / 正文后重新批示。

## 今日简报 · 卡片流

**「简报即工作流」**：滑卡批示本身就是一次结构化任务立项 —— 采纳时选中项自动注入任务目标，跳过 / 收藏同样落入待办与收藏夹。

| 能力 | 说明 |
| --- | --- |
| 六类卡片 | 洞察 / 决策 / 创作 / 待办 / 数据 / 提问，结构化提示词驱动生成 |
| 三种批示 | ← 跳过、↑ 收藏、→ 采纳，键盘 / 触摸 / 拖拽三套交互一致 |
| **卡片内容可交互** | 选项可选、待办可勾、文本可编辑、卡片可跳转；交互态 LocalStorage 持久化 |
| **真实落章** | 双线印面 + SVG 印泥纹理 + 砸下回震，**仅滑卡决策瞬间触发** |
| **个性化排序** | Mock 剧本按历史决策 / 收藏驱动排序；API 模式由 LLM 结构化生成（逐卡运行时校验、超时与失败回退 Mock） |

## 三角色剧本

角色决定 system prompt、简报剧本与工具集，三套数据上下文。

| 角色 | 典型简报 | 核心工具 | 数据上下文 |
| --- | --- | --- | --- |
| **教师** | 班级学情、薄弱知识点、家长会发言、分层练习 | 学情查询、命制试题、错题归因 | 班级成绩（CSV 导入）、作业完成率、专注度 |
| **学校管理** | 校情趋势、督导预警、教师帮扶 | 区域统计、趋势对比、预警规则 | 全校数据聚合、跨班级对比、跨周期对比 |
| **教育局** | 区域指标、学校排行、督导通知 | 区域汇总、政策匹配、通知模板 | 区县指标、连续两学期下滑识别、帮扶范围定位 |

## 架构 · 解耦 Harness 层

业务代码只依赖 `harness/types` 契约，Mock ↔ API 切换零业务改动。

```
src/harness/
├── types.ts             # 核心契约（LLMProvider / AgentProvider / BriefingCard / RolePreset…）
├── providerRegistry.ts  # 统一注册中心，ACTIVE_MODE = 'mock' | 'api' 一键切换
├── llm/                 # MockLLMProvider（流式打字机）+ DeepSeekAdapter 骨架
├── agent/               # ToolRegistry + MockOrchestrator（Plan→Act→Reflect 剧本驱动）+ API 骨架
├── briefing/            # 今日简报卡片 Provider
├── artifacts/           # 文档生成 Provider（教案 / 报告 / 通知模板）
├── memory/              # 记忆分层 Provider（L2 情景 + L3 语义偏好，mock/api 共用）
├── eval/                # 产出自评（规则版评分表，mock/api 共用）
├── roles/               # 三角色预设（system prompt + 工具集）
├── sources/             # SourceProvider 三级优先（CSV 导入 > 远端数据平台 > 静态 seed）
└── scripts/             # 预制剧本：简报卡组 / Agent 步骤 / 文档模板（含降级剧本）
```

| 接入真实模型步骤 | 说明 |
| --- | --- |
| 1 | 实现 `DeepSeekAdapter.streamChat`（OpenAI 兼容 SSE）与 `Orchestrator`（function-calling 优先，Plan-JSON 降级） |
| 2 | 把 `providerRegistry.ts` 的 `ACTIVE_MODE` 改为 `'api'` |
| 3 | 任何输入都有响应：剧本未命中时走角色化降级剧本，演示零翻车 |

## 自进化技能系统（Hermes 式）

Agent 在执行过程中**自动发现 → 自动提炼 → 沉淀 → 复用 → 进化**技能，形成自进化闭环。

| 阶段 | 机制 |
| --- | --- |
| 发现 | trace 摘要 → LLM 复盘 → 候选技能 |
| 沉淀 | 触发词并集、版本 +1、保留原步骤；LocalStorage 持久化 |
| 命中 | API 模式命中技能注入 system prompt；Mock 模式骨架预留 |
| 进化 | 去重校验 + 版本递增；任务完成后自动沉淀 / 进化 |
| 可视化 | 执行轨迹「命中技能 / 已沉淀技能」徽标 + 侧栏技能库面板 + 一键演示向导三幕走完闭环 |

---

## 数据分层与持久化

**Raw（`src/data/seed.ts` 种子数据）→ Aggregated（工具聚合）→ Agent Output（trace / 文档）→ Presentation（渲染）**

| 层级 | 说明 |
| --- | --- |
| 数据源 | SourceProvider 三级优先：**CSV 导入 > 远端数据平台 > 静态 seed**，远端失败自动降级并在 UI 标注「演示数据」 |
| 数据上下文 | 按角色聚合真实数据 → 格式化为 prompt 文本 · 来源标注 + 1800 字符截断护栏 + 单源失败不阻断 |
| 持久化 | 会话 / 收藏 / 文档 / 版本历史 / 偏好画像 / 登录态 / 学习技能 / **记忆分层** 均存 LocalStorage（`edustudio:` 前缀）；设置弹层可一键清空 |
| 教师专属 | 简报页可导入班级成绩 CSV（宽表 / 长表通吃，列名模糊匹配 + 预览确认），简报首卡即基于真实数据生成 |

## 真实落章动效（仅滑卡决策瞬间）

- **双线印面**：跳过（绿）/ 收藏（金）/ 采纳（紫）三色印面，对齐决策语义；
- **SVG 印泥纹理**：随机旋转 ±15°、不规则边缘、油墨深浅随机；
- **砸下回震**：落章后卡片微缩 0.96 → 弹回 1.0，280ms ease-out；
- **保留卡印章定格**：v0.8.2 起保留卡持续展示对应决策印章，已盖章状态一目了然；
- **弱动效偏好尊重**：`prefers-reduced-motion` 下跳过物理 / 砸下回震，仅保留印章定位。

## 部署

### 前端（Vercel，推荐）

纯静态 SPA，**零后端依赖即可上线**（`ACTIVE_MODE` 默认 `mock`，离线可演示）：

1. 在 Vercel 导入本仓库（GitHub：`lzytttttt/EDUStudio`）；
2. Framework 选 **Vite**（自动识别），Build Command `npm run build`，Output Directory `dist`；
3. 也可在仓库根目录执行 `vercel` 一键部署；`vercel.json` 已内置构建参数与 SPA 回退重写。

> `npm run build` 前置执行 Vitest 单测 + `tsc` 类型检查，任一不过则构建失败，天然构成上线质量闸门。

### 轻后端代理（Docker，可选）

key 托管 / 限额 / 审计 / 分享短链 / 任务链 / 错误上报 可一条命令拉起：

```bash
DEEPSEEK_KEY=sk-xxx docker compose up -d        # PowerShell：$env:DEEPSEEK_KEY='sk-xxx'; docker compose up -d
```

前端设置页 → 模式选「代理」，地址填 `http://<主机>:8787/v1`；审计日志与分享 / 任务链数据持久化在 `edustudio-data` 卷。
